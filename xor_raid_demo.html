About XOR & RAID

XOR (exclusive OR) is a fundamental bitwise operation. For any two bits, XOR returns 1 if exactly one bit is 1, and 0 otherwise. Key properties:

  • x ^ x = 0 (any value XOR itself yields 0)
  • x ^ 0 = x (any value XOR 0 is itself)
  • x ^ y = y ^ x (XOR is commutative)
Learn more in the Wikipedia article on XOR.

In RAID (Redundant Array of Independent Disks), XOR generates parity data so that a failed drive can be reconstructed. In 2-drive mode: Parity = D1 ^ D2. In 3-drive mode: Parity = D1 ^ D2 ^ D3. Recovering any single failed drive (including the parity drive) uses the same XOR: XOR all surviving drives together. See the Wikipedia article on RAID, or the XOR video and RAID video from the "Gary Explains" YouTube channel.

How to use this page:

  • Generate Drives — fills each data drive with random bits. You can edit any cell manually before checking parity.
  • Check Parity — enter your XOR calculations in the Parity row, then verify.
  • Show XOR Steps — watch the parity get computed one bit at a time.
  • Simulate Drive Failure — any drive (including the parity drive) may fail; recover it using the survivors.
  • Check Drive Recovery — verify your repair with an animated rollthrough.
  • Print Worksheet — prints the current table for offline use.
